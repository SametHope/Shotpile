fix: give the review card a definite height so it actually renders

The deck made the card absolutely positioned, which broke the height chain:
with `auto` height the image's max-height:100% (image -> imgwrap -> card)
cannot resolve, so the card collapsed to its 2px border and the review showed
an empty area. The old grid layout supplied the height for free.

- #view is height:100% so the chain #view -> .review -> .wrap -> .stage ->
  .deck resolves to a real height.
- .deck .card is height:100% so it fills the deck.
- .review .wrap sets margin:0 to override the .wrap class's margin:0 auto;
  on a flex item auto margins absorb the free space and stop the wrap from
  stretching, which left the card narrow.

The GUI harness now renders a real 2000x1500 image (not a 1x1 GIF) and asserts
the card fills the deck, so this class of bug is caught.
